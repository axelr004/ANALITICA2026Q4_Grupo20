# EA1 - Carga y Creación de Dataset


## Objetivo

Obtener datos desde Hugging Face, cargarlos en un DataFrame de pandas, aplicar transformaciones y generar un resumen en un archivo TXT.

## Archivos del proyecto
- `hf_dataset_loader.py`: clase para cargar el dataset.
- `dataset_summarizer.py`: clase para resumir el DataFrame.
- `EA1_Grupo.ipynb`: notebook que coordina el proceso.
- `resumen_dataset.txt`: resumen generado por el proyecto.
